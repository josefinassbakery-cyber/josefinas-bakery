
JOSEFINA'S BAKERY — BASE ESTABLE

Esta es una base de aplicación web con SQLite persistente.
Incluye:
- pedidos con múltiples productos (carrito)
- estados: Pendiente de elaborar, Pre-elaborado, Listo para entregar, Entregado, Finalizado
- pagos parciales y varios métodos: Efectivo, Zelle, Cash App, Tarjeta y Otro
- notas de pedidos especiales
- base de datos SQLite en un único archivo

Para ejecutar en una computadora:
1. Instala Python 3.11+.
2. Abre una terminal en esta carpeta.
3. Ejecuta: pip install -r requirements.txt
4. Ejecuta: python app.py
5. Abre: http://127.0.0.1:5000

IMPORTANTE:
Esta base todavía necesita publicación en un servidor para tener una URL fija accesible desde el teléfono.
No uses esta versión para producción hasta desplegarla en un servidor con copias de seguridad.
